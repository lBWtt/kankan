# 已发现问题

## P1

1. 动态图片首次加载慢：图片原样转存到本机 `/uploads`；服务器公网带宽为 3 Mbps。一张 5.74 MB 图片实测下载约 16.5 秒，且未设置浏览器缓存。后续需要缩略图/压缩、缓存，并迁移对象存储 + CDN。
2. 项目详情底部仍显示“想看怎么做”：对已经可以直接体验的项目，主行动应是“去体验/打开项目”，而不是把用户引向制作教程。
3. 部分项目的跳转链接不是项目本身：会跳到 Product Hunt 等采集来源页，而非实际产品网站、App Store 或 GitHub 仓库。需要把项目体验链接与来源链接分开，并在审核时校验体验链接。
